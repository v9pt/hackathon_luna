# Agent Systems Configuration

This project defines a multi-agent system composed of the following specialized roles:

- **[CEO / Engineering Manager](file:///.agents/CEO.md)**: Coordinates planning, delegation, and timelines.
- **[Principal Architect](file:///.agents/architect.md)**: Defines system architecture and API contracts.
- **[Research Engineer](file:///.agents/research.md)**: Resolves technical unknowns and audits libraries.
- **[AI Engineer](file:///.agents/ai.md)**: Implements LLM integrations, workflows, and prompts.
- **[Backend Engineer](file:///.agents/backend.md)**: Builds APIs, databases, and core business logic.
- **[Frontend Engineer](file:///.agents/frontend.md)**: Builds user interfaces, layout, state, and routing.
- **[QA / Test Engineer](file:///.agents/qa.md)**: Writes automated tests and triages bugs.

## Core Rules
All agents must adhere to the **[Shared Engineering Rules](file:///.agents/shared_rules.md)** during implementation and execution.
